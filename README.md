## 为什么搬走

这里曾经只做一件事：放安装包。

后来把源码也传上去之后，构建改成 **GitHub Actions 从源码现场编译**。
新仓库里既有源码、又有流水线、又有 Release，三样在一起才能核对：

```
Actions → Build Installer → 某次 run
  能看清：从哪个 commit、装了什么依赖、跑了多少测试、
         构建出来的 exe 里塞了什么、SHA256 是多少
```

而这个仓库里的包是本机编译后上传的，Actions 里查不到过程。
两个仓库并存会让人分不清哪份可信，所以旧的清空、归档。

## 这个仓库里还剩什么

只剩这份说明。

原来的 `v1.2.1-r6` Release、它的附件的 exe / dmg / sha256、
以及当时的发行说明，都已删除。

本仓库设为**只读存档**，历史链接仍可访问，但不会再更新。
